# 🎓 KU Information Literacy Exam Hub (ระบบเตรียมสอบสารสนเทศศาสตร์ & ห้องทดลองบรรณานุกรม)

เว็บแอปพลิเคชันสำหรับฝึกทำข้อสอบและทบทวนเนื้อหาวิชาการรู้สารสนเทศ (Information Literacy) มหาวิทยาลัยเกษตรศาสตร์ วิทยาเขตกำแพงแสน รวบรวมแนวข้อสอบจริงและข้อสอบเข้มข้นกว่า **105 ข้อ** ครอบคลุมทุกบทเรียน พร้อมโหมดเจาะลึกบรรณานุกรม APA 7th และหน้าสรุปสาระความรู้

🌐 **เข้าใช้งานเว็บฝึกทำข้อสอบได้ทันทีที่:** [https://AnthidaC.github.io/ku-info-exam-hub/](https://AnthidaC.github.io/ku-info-exam-hub/)

---

## ✨ ไฮไลต์ฟีเจอร์เด่น (Key Features)

### 1. 🎯 โหมดจำลองสอบจริง (Full Mock Exam 105 ข้อ)
* รวมแนวข้อสอบครบทุกเรื่อง: บรรณานุกรม APA 7th, แหล่งสารสนเทศ, ตรรกบูลีน & คำสั่งสืบค้น, การประเมิน & สังเคราะห์สารสนเทศ, จริยธรรม & กฎหมายคอมพิวเตอร์ พ.ศ. 2560, พ.ร.บ. ลิขสิทธิ์ พ.ศ. 2537, ฐานข้อมูลออนไลน์ และกิจกรรมหอสมุด มก. กำแพงแสน
* ระบบจับเวลาสอบเสมือนจริง 60 นาที (สามารถหยุดชั่วคราวได้)
* แผงข้อสอบ (Palette Grid 1–105) แสดงสถานะข้อที่ทำแล้ว ยังไม่ทำ หรือปักหมุดไว้ทบทวน
* ระบบตรวจคะแนนอัตโนมัติ ตัดเกรดคำนวณเปอร์เซ็นต์ พร้อมแยกวิเคราะห์จุดแข็ง-จุดอ่อนรายหมวดหมู่

### 2. 💎 ห้องทดลองบรรณานุกรม (Bibliography Master Lab - เน้นพิเศษ)
* **ประกอบชิ้นส่วนบรรณานุกรม (Interactive Ordering Drill):** ฝึกเรียงลำดับส่วนประกอบของบรรณานุกรม (ผู้แต่ง, ปี, ชื่อเรื่อง, วารสาร, เล่มที่, เลขหน้า, DOI) ให้ถูกต้องตามแบบ APA Style 7th
* **จับผิดจุดที่เขียนผิด (Spot-the-Mistake Challenge):** ฝึกสังเกตจุดผิดยอดฮิต เช่น การใช้ & แทน and, การตัดยศ/ตำแหน่งวิชาการ, ตัวเอียง, การอ้างอิง In-text, และหน่วยงานที่มีชื่อย่อ
* **รวมสูตรสำเร็จ APA 7th:** คลังตัวอย่างและโครงสร้างมาตรฐาน พร้อมจุดสังเกตสำคัญที่มักออกสอบ

### 3. 📚 หน้าสรุปสาระความรู้ทุกบทเรียน (Comprehensive Study Notes)
* สรุปเนื้อหาทั้ง 6 หมวดหมู่อย่างละเอียด เป็นระบบและอ่านเข้าใจง่าย
* มีตารางเปรียบเทียบสารสนเทศปฐมภูมิ-ทุติยภูมิ-ตติยภูมิ
* ตารางสรุปโทษตาม **พ.ร.บ. คอมพิวเตอร์ พ.ศ. 2560 (มาตรา 5 ถึง มาตรา 16)**
* สรุปข้อยกเว้นการละเมิดลิขสิทธิ์ (Fair Use) ตาม พ.ร.บ. ลิขสิทธิ์ 2537
* แนวทางการใช้ Generative AI สำหรับงานวิจัย (ประกาศ วช.)
* สรุปฐานข้อมูลออนไลน์เฉพาะสาขาวิชา (THAIJO, TDC, IEEE, ERIC, CEIC, Stash, WGSN, Osmosis ฯลฯ)
* คู่มือกิจกรรมนอกชั้นเรียนสำนักหอสมุด มก. กำแพงแสน

### 4. 📊 ระบบบันทึกสถิติและคลังข้อที่เคยตอบผิด (Mistake Drill)
* บันทึกข้อสอบที่ตอบผิดลงใน LocalStorage ของเบราว์เซอร์อัตโนมัติ
* โหมด **"ฝึกทำเฉพาะข้อที่ผิด"** ช่วยฝึกซ้ำเฉพาะจุดที่ไม่แม่นจนกว่าจะได้คะแนนเต็ม 100%

## 🎨 การออกแบบตามมาตรฐาน Apple Design System
* **โทนสีทางการ (Formal White & Royal Blue):** สีหลักคือ **Action Blue (`#0066cc`)** สะอาดตา ภูมิฐาน และเน้นการอ่านเนื้อหาเป็นศูนย์กลาง
* **ฟอนต์ Sarabun:** รองรับภาษาไทยมาตรฐานราชการและสากล สบายตาสำหรับอ่านข้อสอบยาว
* **ระบบจัดวาง (Typography & Spacing):** เนื้อหาตัวหนังสือขนาด 17px (Apple reading pace) พร้อมระยะบรรทัด 1.47 และความโค้งมนแบบ Pill CTA (`rounded-full`)
* **Responsive 100%:** รองรับทั้งหน้าจอสมาร์ตโฟน (มีแถบควบคุม Sticky ด้านล่าง), แท็บเล็ต, และหน้าจอคอมพิวเตอร์ทุกขนาด

## 🚀 การติดตั้งและพัฒนาในเครื่อง (Local Setup)

สามารถเปิดใช้งานได้ทันทีโดยไม่ต้องลง Dependency เพิ่มเติม:
```bash
# Clone โปรเจกต์
git clone https://github.com/AnthidaC/ku-info-exam-hub.git

# เข้าโฟลเดอร์
cd ku-info-exam-hub

# เปิดไฟล์ index.html บนเบราว์เซอร์ใดก็ได้
start index.html
```
